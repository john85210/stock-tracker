📤 手動同步到 GitHub（備援流程）

建議改用「🔗 GitHub 自動同步」設定一次性 Token 之後就不用再手動做這件事了。 但如果暫時沒有設定，或想備份存檔，可以照以下步驟手動上傳剛下載的 data.json：

  1. 到 你的 stock-tracker repo
  2. 點進 data.json → 右上鉛筆圖示 → 全選刪掉 → 貼上新檔內容
  3. 滾到最下面按 Commit changes
  4. 等 1~2 分鐘讓 GitHub Pages 刷新
  5. 重新整理網頁即可看到同步後的狀態

🔗 GitHub 自動同步設定

設定一組 GitHub Personal Access Token 後，往後新增股票、編輯價格、Excel 匯入等任何變更， 會自動 commit 回 data.json，不用再手動下載/上傳。Token 只會存在這台瀏覽器的 localStorage，不會上傳到任何地方。

⚠️ 安全提醒：這台瀏覽器如果被別人拿到（或裝置中毒），對方可能透過開發者工具讀到這組 Token 進而竄改你的 repo。 請務必使用 Fine-grained token，只勾選這一個 repo（stock-tracker）， Permissions 只給 Contents: Read and write，不要用能動到其他 repo 的 classic token。

還沒建立 Token？前往 GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token， Repository access 選「Only select repositories」→ 選 stock-tracker， Permissions → Repository permissions → Contents 設為 Read and write，其餘保持 No access 即可。
